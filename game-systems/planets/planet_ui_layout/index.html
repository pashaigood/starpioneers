Карточка планеты - визуализация, размещение элементов и глубина UX

Цель: точная спецификация визуальной и интерактивной структуры полноэкранной карточки планеты, с учётом игровых потребностей - фокус на понятности, приоритетных действиях, глубине визуализации и минимизации когнитивной нагрузки. Документ описывает расположение элементов, поведение, анимации и примеры микровзаимодействий.

Основные принципы UX (с игровой точки зрения)​

  • Одноэкранная задача: игрок должен видеть контекст (планету), доступные сервисы и иметь возможность выполнить ключевые действия (взлёт, покупка/апгрейд, заправка, ремонт) без переходов между множеством меню.
  • Визуальная глубина: фон - живой вид планеты (3D-превью/видеопетля/частицы), слои UI с разной прозрачностью и параллаксом.
  • Приоритетность: самые важные действия всегда в зоне фокуса и доступны за 1 клик + 1 подтверждение.
  • Поступательное раскрытие: подробности доступны в той же карточке через вкладки/панели, без перехода на новые экраны.
  • Игровое ощущение: анимации, звук и микротексты повышают доверие и дают понятную обратную связь.

Экран - слои и зоны​

Разделение экрана на 3 визуальных слоя:

  • Слой 0 - Фон (полная заливка): динамическое изображение планеты (параллакс, медленное вращение).
  • Слой 1 - Холст: основные крупные элементы - визуал планеты (слева), список сервисов (справа).
  • Слой 2 - HUD: панель быстрых действий, тосты, модальные окна, всплывающие подсказки.

Разметка (для широкого экрана; мобильная адаптация описана ниже):

  • Сетка: адаптивная 12-колоночная.
  • Отступы безопасности: 48 px по краям.
  • Левая колонка (колонки 1-7): большой визуал планеты + полоса основных характеристик под ним.
  • Правая колонка (колонки 8-12): список сервисов (вверху, прокручиваемый) + панель деталей (внизу).
  • Верхняя панель (фиксированная, по всей ширине): заголовок (название планеты, значки, кнопка "Взлёт").
  • Нижняя панель (фиксированная): журнал активности / чеки (сворачиваемый), контекстные подсказки.

Пример размеров:

  • Область визуала планеты: 60% ширины, min-height 520px, центрирована по вертикали.
  • Список сервисов: 40% ширины, max-height ~60% высоты окна, высота одного элемента ≈ 64px.
  • Панель деталей: 40% ширины, 40% высоты окна, прокручиваемая.

Элементы и поведение​

  1. Верхний заголовок (фиксированный)

    • Позиция: фиксированная сверху, высота ~72px.
    • Слева: иконка назад + название планеты (H1) + маленькая иконка ViewKey.
    • В центре: компактные бейджи и статусные индикаторы:
      • Пригодность (habitability) - компактная шкала.
      • Бейдж специализации.
      • Бейдж контролирующей фракции (faction) и индикатор отношения игрока к фракции (reputation bar / status: Friendly/Neutral/Hostile).
      • Локальное время (опционально).
    • Справа: быстрый доступ к ресурсам игрока и основным действиям:
      • Отображение кредитов игрока (Credits) и иконка валюты - мгновенный доступ к сумме.
      • Основные действия: [Взлёт (главная кнопка)] и [Открыть карту].
    • Поведение: кнопка "Взлёт" ярко выделена; при наведении/фокусе показывать подсказку клавиши (например, "T - взлёт"). При клике на бейдж фракции - открыть подробности фракции (отношения, миссии, торговые бонусы).

  2. Визуал планеты (левая колонка)

    • Большой 3D-превью или видеопетля: медленное вращение по rotationAngle, мягкая виньетка.
    • Параллакс: движение курсора/аналога смещает подсветку/камера для ощущения глубины.
    • Наложения:
      • Микро-индикатор орбиты/временной линии (показывает запланированные события).
      • Превью маркеров (если необходимо).
    • Взаимодействие:
      • Клик/таск для поворота превью (инерция вращения).
      • Двойной клик - полноэкранный просмотр визуала.
    • Доступность: альтернативная статичная картинка для слабых устройств.

  3. Полоса основных характеристик (под визуалом)

    • Ряд компактных показателей: радиус, радиус орбиты, период вращения, население/пригодность (%).
    • Каждый показатель - интерактивная "таблетка" с подсказкой.

  4. Список сервисов (правая верхняя колонка)

    • Вертикальный список; каждая карточка сервиса содержит:
      • Иконку (слева), название сервиса (заголовок), короткий статус (подзаголовок), кнопка быстрого действия (справа).
    • Приоритет порядка (по умолчанию): 1) Верфь/Магазин кораблей, 2) Заправка, 3) Ремонт, 4) Рынок, 5) Доска миссий, 6) Бар/социальные сервисы.
    • Сортировка: переключатель "По доступности", "По релевантности", "По удалённости".
    • Микровзаимодействие: при наведении плитка приподнимается и показывает быструю кнопку (например, "Купить" или "Заправить").

  5. Панель деталей сервиса (правая нижняя колонка)

    • Содержимое зависит от выбранного сервиса.
    • Возможные вкладки: Обзор | Инвентарь | Апгрейды | История.
    • Верфь / Магазин кораблей:
      • Сетка/список кораблей: миниатюра, имя, класс, краткие характеристики (скорость, груз, HP), цена.
      • Раскрытие элемента (аккордеон) показывает компоненты и кнопки "Купить / Инспектировать / Установить".
      • Функция "Сравнить": помечать 2-3 корабля для сравнения бок-о-бок.
    • Заправка:
      • Цена за единицу, ползунок и быстрые пресеты (25/50/Full), итоговое количество топлива и сумма.
      • Подтверждение inline; предварительная проверка достатка средств.
    • Ремонт:
      • Недостающее HP, цена за HP, быстрые режимы (Полный / Критический), кнопка "Починить сейчас".
    • Рынок:
      • Таблица: Название | Цена покупки | Цена продажи | Остаток | Быстрая покупка.
      • Поиск и фильтры (товары / комплектующие / модули кораблей).
    • Панель деталей появляется со слайд-ап анимацией и тенью.

  6. Панель быстрых действий (Persistent Quick Actions)

    • Горизонтальная панель или плавающее кольцо: [Взлёт] (главная), [Быстрая заправка], [Быстрый ремонт], [Открыть полный рынок], [Верфь].
    • Всегда видна; поддерживает хоткеи:
      • T - Взлёт
      • F - Быстрая заправка
      • R - Быстрый ремонт
      • M - Рынок
      • S - Верфь
    • На мобильных - свернута в плавающую кнопку (FAB), раскрывающуюся по тапу.

  7. Журнал активности / чеки (нижняя полоса)

    • Короткие записи с временной меткой; кликабельны для просмотра полного чека.
    • Возможность отмены последнего действия в течение 5-10 секунд (optimistic UI).

Микровзаимодействия и анимации​

  • Открытие карточки: плавное появление + лёгкий zoom-эффект визуала (0.98 → 1.0).
  • Наведение на сервис: плитка поднимается (translateY 6-8px) и тень усиливается.
  • Подтверждения: встраиваемый слайд-даун с чеком и звуком; успех - зелёный пульс.
  • Взлёт:
    • Нажатие "Взлёт" → модальное подтверждение в центре с размытием фона.
    • Анимированный список проверки (топливо, ремонт) с зелёными/красными индикаторами.
    • При подтверждении - лёгкая вибрация камеры, затем fade-out интерфейса и возврат в полётный HUD.
  • Покупка:
    • Кнопка "Купить" превращается в индикатор прогресса → галочка успеха → чек в журнале.
  • Ошибки:
    • Встроенные полосы ошибок + верхний тост; тосты стекаются (макс. 3).

Визуальный язык, цвета и типографика​

  • Следовать общей стилистике HUD проекта: тёмные полупрозрачные панели, неоновый акцент для CTA.
  • Шкала пригодности (habitability): красный → оранжевый → зелёный.
  • Главная CTA (Взлёт): акцентный цвет (напр., "электрический циан") с лёгким свечением.
  • Размеры шрифтов:
    • H1 (название планеты): 28-34px
    • Названия сервисов: 18px
    • Основной текст: 14px
  • Иконки: геометрический стиль, единая сетка 24/32px.

Глубина и восприятие​

  • Параллакс слоёв: звёздный фон (глубина -30%), планета (0%), UI (+10%).
  • Тени и размытия: мягкий гауссовый blur фона при показе модалей.
  • Звуковые эффекты: короткий звук подтверждения, тон ошибки, "шуршание" для чека.

Доступность и управление​

  • Клавиатура и хоткеи (см. выше).
  • Контроллер: крестовина/левый стиком навигировать сервисы; A = выбор; B = назад.
  • Масштабирование текста, режим высокого контраста, метки для экранного чтеца для критичных кнопок.
  • Параметр "уменьшение анимации" для пользователей, которые предпочитают статичный интерфейс.

Мобильные и планшетные варианты​

  • Responsive: визуал планеты становится верхним блоком; список сервисов - аккордеон под ним.
  • FAB заменяет панель быстрых действий.
  • Целевые области не менее 44-48px.
  • Анимации: ограничены до opacity/transform; минимизировать JS-операции при открытии.

Работа с данными и производительность​

  • Использовать snapshot-паттерн: считывать данные CelestialModel под lock в кратковременную view-модель и привязывать UI к ней.
  • Подписываться на события изменения рынка/сервисов только при открытой карточке; отписываться при закрытии.
  • Предзагрузить миниатюры кораблей и иконки рынка, когда игрок подходит к планете, чтобы избежать фризов.

Примеры пользовательских сценариев​

  1. Игрок приземлился → карточка планеты открыта, виден визуал и сервисы.
  2. На визуале горит бейдж "Низкий уровень топлива" → игрок нажимает Быструю заправку → ползунок показывает сумму → подтверждение → топливо зачислено, чек в журнале.
  3. Игрок открывает верфь → сравнивает два корабля → покупает новый корпус → подтверждение, чек, и (опционально) мгновенное применение апгрейда.
  4. Игрок нажимает Взлёт → появляется окно проверки (Fuel OK / Repair needed) → игрок чинит или подтверждает → интерфейс переходит в режим полёта.

Критерии приёмки (визуал и взаимодействие)​

  • Карточка планеты открывается при посадке с плавной анимацией и видимой кнопкой "Взлёт".
  • Основные быстрые действия доступны в пределах 1 клика и подтверждаются в том же окне.
  • Верфь поддерживает сравнение и покупку без перехода на отдельную сцену.
  • Интерфейс остаётся отзывчивым на среднем железе; мобильная версия использует упрощённые анимации и интерфейс.
  • Есть настройки доступности (размер текста, уменьшение анимации, высокий контраст).
