Combat Design — Real‑time Rhythm Targeting (no direct piloting, no CP, no queues)

Цель

  • Бои — полностью в реальном времени, без тактической паузы и без прямого пилотирования.
  • Игрок только указывает цели / режимы, но остаётся постоянно вовлечён благодаря ритмическим «окнам» и реакциям на телеграфы.
  • Без Command Points и без длинных очередей; только быстрые решения и ритм.

Ключевые принципы

  • Ритм как главный элемент вовлечения: глобальный beat, execution windows для конкретных действий/реакций.
  • Telegraphs: враг показывает, что готовит — игрок реагирует в окне (увеличить щиты, сменить тип оружия, снизить урон).
  • Быстрая смена режима оружия/приоритетов по горячей клавише — мгновенная тактическая реакция.
  • Массовые сражения: механики масштабируются на несколько врагов через приоритеты, групповые действия и «фокус/разброс».

Core loop — что игрок делает в бою (одно предложение)

  • Смотрит на индикаторы целей и телеграфы → назначает/переключает режим/цель (быстрый хоткей) → в execution window делает ритм‑клик/подтверждение → эффект команды усиливается.

UI — спецификация (макет, поведение, фидбек)​

Цель UI

  • Дать игроку максимум релевантной информации за минимальное время взгляда.
  • Обозначать telegraphs и execution windows чётко и недвусмысленно.
  • Поддерживать клавиатурный / геймпадный контроль без мыши.
  1. Общая компоновка (2D HUD)
  • Центр/экран:
    • Малая карта/фон — не загромождает центр экрана, основные события визуализируются над кораблём (легкие FX).
  • Верхний левый угол:
    • Мини‑инфо игрока (имя/короткое состояние), короткий статус корабля (hp %, shields % — компактно).
  • Верхний правый угол:
    • Счётчик волн / таймер боя / общая цель миссии.
  • Правый/левый край (вертикальные колонки) — Target Cards (по одному на видимого врага)
    • Каждая карточка: маленький спрайт, имя/тип, полоска Shield (сегментированная), полоска Structure (HP), telegraph indicator (полоса countdown), recommended mode маркер (иконка: Energy/Kinetic/EMP), threat dot (цвет).
    • Карточки сортируются по ThreatScore (топ → верх).
    • Хоткей над карточкой (цифра) — быстрый фокус на цель.
  • Нижняя центральная полоса — Beat Bar / Execution Window UI
    • Горизонтальная анимированная полоса (пульс), центр — окно эффективности (визуально выделено).
    • При появлении execution window для конкретной цели сверху/под полосой добавляется пометка target‑id или small icon.
    • Кнопка/подсказка: "Space / A" — нажать для подтверждения.
    • Combo индикатор справа от полосы (число/степень).
  • Нижний левый — Mode Switch & Quick Actions
    • Иконки режимов (Kinetic / Energy / EMP) с подсказками хоткеев (Q / E / R).
    • Group action (Overload) — отдельная большая иконка с индикатором cooldown (если используется).
  • Нижний правый — Combat Log (только важные строки): telegraphs, interrupts, subsystem disabled, kill messages (короткий список).
  1. Визуальные паттерны и цвета
  • Telegraph indicator: желтая полоса с быстрым бегунком → к моменту удара меняет цвет на красный (warning).
  • Execution window: яркий контрастный узор внутри Beat Bar (например, белая рамка + пульсация).
  • Success feedback: зелёная вспышка на карточке цели + краткий всплывающий текст "+X% dmg" и звук.
  • Fail feedback: серая / тусклая вспышка, небольшой каустический звук (без негативного длительного штрафа).
  • Recommended mode highlight: подсвечивать иконку на карточке и кратко моргать, когда смена режима имеет смысл.
  1. Поведение при множественных врагах
  • Primary target выделяется контуром на карточке и на HUD (более яркая рамка).
  • Group execution: при удержании подтверждающей кнопки или двойном тапе Beat Bar переводится в group mode — подсвечиваются топ‑K карточек.
  • При большом количестве врагов карта карточек сворачивается в пагинацию (стрелки переключения).
  1. Управление (клавиатура / геймпад)
  • 1..9 — выбрать/фокус на соответствующую target card.
  • Tab — cycle primary target.
  • Q / E / R — переключить режим оружия (Kinetic / Energy / EMP).
  • Space (или A на геймпаде) — ритм‑клик / подтвердить execution window.
  • Shift + Space — group application (если поддержано).
  • Esc — открыть тактичесную паузу (опционально, для настройки), но не требуется для реального боя.
  1. Звуковая и тактильная обратная связь
  • Каждый telegraph генерирует выделенный звуковой маркер (low → medium → high).
  • Execution window tick sound в начале окна и success chime при попадании.
  • Haptics: короткая вибрация при успехе/неуспехе на геймпаде.
  1. Доступность и настройки
  • Colorblind mode: альтернативные паттерны/символы вместо цвета для telegraph/target threat.
  • UI scale: 0.75–1.5.
  • Optional audio cues toggle.
  • Keyboard‑only mode: все элементы доступны без мыши, с явными хоткеями.
  1. Минимальная реализация для прототипа (технические примечания)
  • TargetCard prefab (UXML/UIToolkit or Unity UI): bind to Target model (id, shields, hp, telegraphTime, recommendedMode).
  • BeatBar component: ticking visual, exposes OnExecutionWindowStart(targetId, duration) event.
  • Input mapping: central RhythmInputHandler listens to Space / gamepad A and calls CombatTacticsManager.TryConfirmWindow(targetId).
  • Visuals: use simple sprites + animated fill bars; avoid expensive shaders for prototype.
  1. Сценарии использования (короткие)
  • Telegraph появляется для enemy A → TargetCard[A] начинает countdown → BeatBar подсвечивает window → игрок нажимает Space вовремя → TargetCard[A] показывает success FX и наносится уменьшенный урон/перехват.
  • Несколько телеграфов подряд → игрок выбирает primary (1) и нажимает Space, чтобы применить усиление к primary; double‑tap = group.
  1. UX‑правило: одна цель — один взгляд
  • Информация для принятия решения должна умещаться в одном взгляде: карточка, telegraph bar, beat bar и хоткей. Не требовать навигации по меню.

Заключение​

  • UI — минимален, контекстен и оптимизирован под быстрые реакции: target cards + beat bar + mode hotkeys дают все необходимые инструменты для ритмичных реальных боёв без микроконтроля кораблей.
  • Прототипную реализацию UI рекомендую сделать в виде нескольких prefab'ов (TargetCard, BeatBar, ModePanel) и привязать к CombatTacticsManager/Target models для быстрой итерации.
